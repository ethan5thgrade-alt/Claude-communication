# Agent Mesh — Status

**Shipped.** Agent Mesh is a personal + friend tool: a single-file broker that
relays messages and channels between Claude Code sessions on the LAN (or over a
cloudflared tunnel to a friend), with an audit trail and a dashboard UI. There
is no SaaS, no public launch, no roadmap to a product.

## Possible next steps (personal scope only)

- Stable named cloudflared tunnel instead of the rotating quick-tunnel URL.
- Quality-of-life CLI flags on `scripts/mesh` as real use surfaces gaps.
- Tighten the friend-invite flow if a new device class shows up.

These are opportunistic, not commitments. The `main` branch is the source of
truth; if it's not in the code, it's not planned.

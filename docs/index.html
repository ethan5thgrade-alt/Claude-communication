AGENT MESH

Make your Claude Codes talk to each other.

A tiny broker that relays messages and channels between Claude Code sessions on your laptop (or over a tunnel to a friend), with an audit trail and a dashboard you can open from your phone. Self-hosted, no accounts — a personal + friend tool, not a product.

Quickstart

# install deps + run the broker
$ python3 -m pip install --user websockets aiohttp
$ python3 broker.py

# launch a mesh-wired Claude Code session (one per terminal)
$ scripts/mesh-claude alpha
$ scripts/mesh-claude bravo

# message between them from inside a session
$ scripts/mesh send cc-bravo "can you read this?"

Open http://localhost:8765 for the dashboard.

Get started

From zero to a working mesh in 5 minutes.

You'll clone the repo, start one Python process, attach two Claude Code bots, and watch them reply. Everything stays on your laptop.

1Prereqs

You need three things installed:

  • Python 3.10+ — python3 --version
  • Claude Code CLI — install instructions, then claude /login with any Anthropic account
  • git — to clone the repo

Run claude --version to confirm it's on your PATH.

2Install

$ git clone https://github.com/ethan5thgrade-alt/Claude-communication.git
$ cd Claude-communication
$ python3 -m pip install --user websockets aiohttp
# optional, enables LAN discovery:
$ python3 -m pip install --user zeroconf
Note: The broker only needs websockets and aiohttp. zeroconf is optional — it lets the broker advertise itself on the local network so other devices can find it.

3Start the broker

In one terminal tab:

$ python3 broker.py
[broker] Plugin catalog: ... plugins under ~/.claude/plugins/cache
[broker] server listening on 0.0.0.0:8766
[broker] Broker started: UI=8765 instances=8766

Now open http://localhost:8765 in your browser. You'll see the dashboard with no instances yet.

4Start two bots

In two more terminal tabs, run one of these in each:

# Tab 2: Alpha (frontend persona)
$ scripts/claude-talk-bot cc-alpha --persona alpha --reply-to-human \
      --max-turns 30 --budget-usd 0.10

# Tab 3: Bravo (backend persona)
$ scripts/claude-talk-bot cc-bravo --persona bravo --reply-to-human \
      --max-turns 30 --budget-usd 0.10

Each script:

  • Polls the broker's REST API for new messages addressed to it
  • Passes them to claude -p with the team-aware system prompt
  • Sends the reply back through the broker
Cost cap: --budget-usd 0.10 tells claude to refuse to spend more than 10¢ per turn-cycle. --max-turns 30 limits how many poll-cycles the bot will live before exiting. Tune up only if you trust the loop.

Refresh the dashboard — Alpha and Bravo should now appear in the INSTANCES sidebar with green dots.

5Send your first message

Option A — Direct message

Click Alpha in the sidebar. Type a message in the composer and hit send. Within a few seconds you'll see the reply appear in the chat thread.

Option B — Broadcast to everyone

Click BROADCAST in the chat list. Both Alpha and Bravo will reply. Replies stay in the BROADCAST thread (not split into their individual threads).

Option C — Create a channel

  1. In the chat list, click + NEW under GROUPS
  2. Name it (e.g. team) and check both Alpha + Bravo
  3. Hit CREATE — the new channel appears in the sidebar
  4. Click it, send a message. The broker fans out to both members, replies come back tagged with the channel

Each channel has its own isolated history — switching to Alpha's individual thread won't show channel messages, and vice versa.
